# 💈 Corte Nobre Barbearia

Site moderno e responsivo desenvolvido para a Corte Nobre Barbearia, com design clean, cores neutras e tipografia profissional. Estruturado para conversão, conta com seções de serviços, diferenciais, depoimentos e botão de WhatsApp para agendamentos rápidos, focado em atrair clientes e gerar mais resultados.

## ✨ Destaques

- Layout **responsivo**, pensado primeiro para o celular
- Contato direto pelo **WhatsApp**, para converter visitante em cliente
- Animações suaves com **Motion** e ícones **Lucide**
- Página única, leve e com carregamento rápido via **Vite**

## 🛠️ Tecnologias

| Camada | Ferramenta |
|---|---|
| Interface | React + TypeScript |
| Estilo | Tailwind CSS |
| Animações | Motion |
| Build | Vite |

## ▶️ Como rodar localmente

```bash
git clone https://github.com/Bruno-Gadelha25/Barbearia-Nobre.git
cd "Barbearia-Nobre/corte nobre"
npm install
npm run dev
```

Acesse **http://localhost:3000**.

```
corte nobre/
```
